# 开发里程碑与验收标准

当前版本：`1.2.0`（本地 MVP，Windows 与 Android 个人使用版）。

## 已完成：本地桌面 MVP

- Flutter Windows/Android 工程、Drift SQLite 和基础组件测试。
- 本地任务创建、编辑、完成、备注、截止日期时间、回收站及 30 天自动清理。
- 创建时间、标题、截止时间和手动拖动排序；手动排序可在正常退出后恢复。
- Windows 自绘窗口栏、桌面固定模式、始终置顶、系统托盘和 Inno Setup 安装包。
- Android 状态栏安全区、回收站入口、点击编辑、独立勾选完成和长按拖动排序。
- Android 常驻待办汇总通知、多次提醒时间、闹钟服务及备用提示音、通知权限与精确闹钟权限处理；任务提醒通知点击后定位到对应任务，真机效果仍需验收。
- Windows 到期时应用自身的右下角弹窗与系统提示音。
- 截止日期与提醒时间分开设置；提醒日期使用日历，时间可滚动或直接输入；支持全天任务和手机窄屏编辑器布局。
- 最多三层子任务拥有完整任务字段，支持逐层展开、同级手动排序；完成或删除主任务会递归处理后代。
- 个性化设置可控制列表默认展开子任务，以及 Windows 固定模式是否显示子任务。

1.2.0 构建验收：`flutter analyze`、`flutter test`（16 项）通过；Windows Release、Inno Setup 安装包和 Android Release APK 均构建成功。Windows 安装包 ProductVersion 为 `1.2.0`；Android 包内 versionName 为 `1.2.0`、versionCode 为 `7`。实际安装、升级、子任务交互及通知点击定位仍需在目标设备上验收。
