# 开发里程碑与验收标准

## 阶段 0：确认与骨架

确认待决策项；创建 Flutter 工程、环境配置、主题、路由、CI 基线、MySQL 数据库和轻量 API 服务。

验收：Windows/Android 均可启动；CI 能完成格式检查、静态分析和空测试。

## 阶段 1：本地单机 MVP

完成清单、任务、筛选、排序、完成状态、子任务、备注、附件和数据库迁移。

验收：无网络连续操作不丢数据；重启后数据仍在；基础页面有组件测试。

## 阶段 2：账号与云同步（暂缓）

该阶段暂缓。当前不实现邮箱 Auth、API 权限、pull/push、定时拉取和云端同步，保留现有 MySQL/Node.js 方案文档作为后续设计记录。

恢复开发后再验收两台设备同步、断网编辑、双端并发和重试场景。

## 阶段 3：数据治理

完成回收站、恢复、彻底删除、账号删除和审计日志。

验收：viewer 无法写入；被移除成员不能继续读取；删除与恢复规则可验证。

## 阶段 4：个人部署准备

完成性能、无障碍、崩溃、隐私说明、图标、Windows 构建包、Android APK 和备份恢复演练。

验收：测试矩阵通过；生产密钥不进仓库；可从上一个版本回滚；干净设备可安装升级。

## Definition of Done

需求有验收用例；代码通过格式化、静态分析和测试；迁移经过演练；错误可定位；文档同步更新；至少一名非开发用户完成冒烟测试。
