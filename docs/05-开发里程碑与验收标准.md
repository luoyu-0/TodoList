# 开发里程碑与验收标准

## 已完成：本地桌面 MVP

- Flutter Windows/Android 工程、Drift SQLite 和基础组件测试。
- 本地任务创建、编辑、完成、备注、截止日期、回收站及 30 天自动清理。
- 创建时间、标题、截止时间和手动拖动排序；手动排序可在正常退出后恢复。

验收：`flutter analyze`、`flutter test` 通过；Windows Release 和安装包能够构建。
