# 后续云端接口与安全设计

本文件描述已确认但尚未实施的云端功能。当前客户端不发起登录、邮件、附件或同步网络请求。

## 认证

- 注册：邮箱 + 密码，服务端发送 6 位一次性验证码。
- 验证：验证码有效期 10 分钟、最多尝试 5 次、发送间隔至少 60 秒；只保存验证码哈希。
- 登录：仅 `email_verified_at` 非空的用户可登录并启用云同步。
- 密码使用 Argon2id 或 bcrypt 哈希；客户端不保存明文密码。
- 登录后签发短期 access token 和可撤销 refresh token。

邮件真实性必须以完成邮箱验证为准，不能只检查邮箱格式。

## API 与权限

- 后端使用 Node.js + Fastify + Prisma + MySQL。
- 所有资源按 Token 中的 `user_id` 隔离；首发不做账号间共享。
- 写操作带 `operation_id`，服务端保证幂等。
- API 校验 Token、请求体 schema、资源归属、输入长度和请求频率。

## 附件与部署

- 单文件最大 10 MB，云端文件存放在 Linux 服务器指定数据目录，文件名不能直接用作磁盘路径。
- 下载与删除必须鉴权；服务器应校验 MIME 类型和实际文件类型。
- HTTPS、MySQL 凭据、JWT 密钥和 SMTP 凭据均通过服务器环境变量管理，禁止提交到仓库。
- MySQL 与附件目录分别备份，并定期验证恢复流程。
