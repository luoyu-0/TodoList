# 产品需求与业务流程

## 当前本地 MVP

### 任务

- 新建任务时标题必填；备注、截止日期、具体时间和提醒时间可选。首次提醒初始取截止时间并独立保存，也可新增多次提醒；提醒日期通过日历选择，具体时间既可通过滚轮选择，也可输入 24 小时制 `HH:mm`。截止日期可设置为全天。
- Windows 端右键任务可打开详情并再次编辑；Android 端点击任务主体编辑。
- 仅点击勾选框可完成任务；普通列表中完成任务仍保持当前排序位置，完成任务仍保留在任务列表中。
- 删除任务会移入应用内回收站，不会进入设备系统回收站。

### 回收站

- 可查看已删除任务、恢复任务、单个永久删除或批量永久删除。
- 删除满 30 天的任务会在应用启动及运行期间的定时清理中自动永久删除。

### 排序

- 默认按创建时间排序。
- 可按标题字典序、截止时间或手动顺序排序，所有排序均支持升序/降序；未设置截止时间的任务在截止时间排序中始终排在最后。
- 拖动任务会切换为手动排序。手动排序在本次会话中只更新内存，应用从系统托盘正常退出时再写入 SQLite，以避免列表刷新闪动。
- Android 端长按任务即可拖动排序；Windows 端使用任务右侧的拖动手柄。Android 拖动结束后立即写入 SQLite，确保应用被系统终止后顺序仍可恢复。Pin 模式继续将已完成任务排在后面。

### 本地提醒

- Android 端常驻一条待办汇总通知，显示未完成任务数量和任务标题，点击后打开应用。
- 首次提醒默认取截止时间；全天任务默认在截止日 09:00 提醒。用户可修改首次提醒、新增或删除额外提醒，也可关闭该任务的全部提醒而保留时间设置。Windows 端使用应用自身的右下角圆角弹窗并播放系统提示音。
- 任务完成、移入回收站或修改截止时间后，应用会取消或重建对应提醒。
- Android 提醒由系统闹钟定时触发前台闹钟服务，尝试循环播放系统默认闹钟铃声；若铃声无法启动，使用备用提示音。响铃期间临时提高非静音的闹钟音量，停止后恢复。通知栏保留任务提醒，点击后打开应用并定位到对应任务，不再使用全屏闹钟页。精确闹钟权限未授权时回退为系统允许的非精确提醒。

### Windows 桌面体验

- 自绘应用顶部栏，提供最小化、最大化/还原、隐藏到托盘等操作。
- 点击关闭按钮仅隐藏窗口和任务栏图标，应用继续驻留系统托盘。
- 托盘左键可打开窗口；右键菜单提供“打开 TodoList”和“退出 TodoList”。退出时会保存待写入的手动排序并关闭本地数据库。
- 固定到桌面后窗口不显示在 Windows 任务栏，仍显示托盘图标。固定窗口最多展示 5 条任务，可拖动窗口、调整尺寸、临时隐藏本次固定模式中的某条任务，并切换始终置顶。
- 应用会为未完成且设置了未来提醒时间的任务注册本机计时器；提醒时间到达时即使主窗口隐藏在托盘，也会弹出提醒。
- 固定与正常窗口各自恢复上次的位置、大小及置顶状态。

### Android 适配

- 使用系统 `AppBar` 自动避开状态栏，不显示 Windows 专用的 Pin、最小化、最大化、关闭和托盘控件。
- 回收站入口位于标题栏右侧；任务及回收站数据保存在应用专属 SQLite 数据库中。

## 后续功能

邮箱注册登录、同账号多设备同步、子任务、附件、附件清理和导入导出均未实施；其目标方案记录在后续文档中，不应视为当前版本功能。
