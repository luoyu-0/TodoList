# 产品需求与业务流程

## MVP

必须包含：邮箱注册登录和邮箱验证；游客本地模式；清单创建/重命名/归档/删除；任务创建、编辑、完成、截止日期、优先级、标签、排序；可选子任务、备注和附件；离线读写、登录后的自动同步、失败重试；回收站、恢复和彻底删除；账号删除。

第一版不做：通知、评论、复杂依赖、重复任务、番茄钟、小组件、第三方导入、账号间共享、计费和端到端加密。

## 页面

首次启动：欢迎 → 选择游客模式或邮箱登录/注册 → 游客进入本地库，邮箱验证成功的用户初始化云同步。

主页面：收件箱、今天、即将到期、已完成、清单。清单页支持任务列表、筛选、排序、快速新增。任务编辑页支持标题、备注、截止日期、优先级、标签、子任务、附件和删除。设置页包含账号、主题、同步状态、数据导出和删除账号。

## 核心流程

创建任务：输入 → 本地校验 → 写入本地库 → 写同步队列 → UI 立即显示 → 联网上传 → 服务端鉴权/权限校验 → 广播 → 其他设备应用。

编辑或完成：每次修改生成带 operation_id 的幂等操作；完成任务后更新完成状态。

删除：先写 deleted_at 软删除并从默认列表隐藏；回收站内可恢复，超过保留期由服务端清理。

注册验证：输入邮箱和密码 → 服务端校验邮箱格式、密码强度和频率 → 发送一次性验证码 → 验证成功后标记 email_verified → 允许登录并初始化云同步。未验证账户不能创建云端数据。

登录同步：邮箱登录成功 → 获取服务端 Token → 上传或下载数据 → 执行本地数据合并 → 进入同步状态。游客转登录时必须明确提示“本地数据将与云端合并”。

离线恢复：显示本地库 → 检查网络 → 按游标拉取 → 上传待同步操作 → 处理冲突 → 推进游标。失败采用指数退避并支持手动重试。

## 非功能目标

- 冷启动本地数据 2 秒内可见，普通操作本地响应 100 毫秒内。
- 在线设备同步延迟目标 5 秒内。
- 同步接口必须幂等，重试不能产生重复任务。
- 删除可撤销，删除账号必须二次确认。
