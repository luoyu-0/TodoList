# 已确认决策与暂缓范围

## 已确认

- 产品名称为 TodoList，首发面向个人使用，预期总用户数不超过 100 人。
- 客户端使用 Flutter，同时支持 Windows 11 和 Android；Android 开发目标对齐 Android 16。
- 本地数据使用 SQLite + Drift，应用采用本地优先设计。
- 后续云端使用 Node.js + Fastify + Prisma + MySQL，部署在已有 Linux 轻量云服务器，并使用已有域名和 HTTPS 证书。
- 账号采用邮箱 + 密码注册登录，注册必须完成 SMTP 邮箱验证码验证，防止仅靠邮箱格式伪造账号。邮件层使用 Nodemailer + SMTP，服务商后续确定。
- 云端仅同步同一账号的多台设备，不做账号间共享。
- 云端附件保存在服务器本地磁盘，客户端附件保存在 App 专属目录，单文件最大 10 MB。
- 回收站属于 TodoList 应用内部，不是 Windows 或 Android 系统回收站；保留 30 天后自动清除。

## 当前已落地

- 本地任务、备注、截止日期、完成状态、回收站和排序。
- Windows 桌面固定模式、始终置顶切换、系统托盘和安装包。

## 暂缓

- 邮箱认证、MySQL 云端数据、附件上传、同步队列和多设备同步。
- 子任务与附件编辑界面。
- 通知、账号间共享、导入导出、账号删除和应用商店发布。

后续开始云端开发前，应先确认 SMTP 服务商、服务端运行账户、MySQL 账号权限、附件目录和备份策略。
