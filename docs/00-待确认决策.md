# 待确认决策

以下问题会影响账号、数据模型、同步和部署方式。未确认前，本文档中的选择均为默认建议。

## 需要确认

1. 云端 API 后端使用哪种语言？已确认 Node.js + Fastify + Prisma。
2. MySQL 部署在哪里？已确认已有 Linux 轻量云服务器、域名和 HTTPS。
3. 附件存储在何处？已确认云端服务器本地磁盘，客户端 App 专属目录。
4. 邮箱登录采用密码登录，还是邮箱验证码/登录链接？已确认邮箱 + 密码，并通过邮箱验证码完成注册验证。
5. “云端共享”是否只需要多设备同步，还是需要把清单分享给其他账号？已确认仅同一账号多设备同步。
6. 是否需要账号删除时同时删除云端全部数据？已确认支持。
7. 邮件服务是否先抽象为 Nodemailer + SMTP？已确认，具体服务商后续通过环境变量配置。

## 默认决策

- 首发用户规模 100 人以内；只做个人使用和同一账号多设备同步。
- 登录后云同步；游客模式只保存本地，登录时提供本地数据合并。
- MVP 包含可选子任务、附件和备注；不做通知、评论、复杂工作流和 E2EE。
- SQLite 是 UI 的真实数据源，云端是同步副本。
- 冲突按字段合并；同一字段同时修改时最后写入胜出，并保留审计日志。
- 应用名为 TodoList；只需生成可安装包，不做商店发布。
- 客户端按 Android 16 对齐；Windows 端提供个人可运行的构建产物。
- 后端部署到已有轻量云服务器，使用已有域名和 HTTPS 证书。
- 附件存服务器本地磁盘；客户端存 App 专属存储目录；单文件不超过 10 MB。
- 服务器系统为 Linux。
